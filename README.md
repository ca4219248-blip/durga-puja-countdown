# Durga Puja 2026 Countdown

A live countdown to Durga Puja 2026 (Durgotsav), built as a single self-contained HTML page — no frameworks, no dependencies.

## Durga Puja 2026 schedule

| Date | Day |
|---|---|
| Sat, 10 October 2026 | Mahalaya |
| Fri, 16 October 2026 | Maha Shashthi (Bodhon) |
| Sat, 17 October 2026 | Maha Saptami (Navapatrika) |
| Mon, 19 October 2026 | Maha Ashtami & Maha Navami (Sandhi Puja 10:29–11:17 AM) |
| Tue, 20 October 2026 | Vijaya Dashami (Sindoor Khela) |
| Wed, 21 October 2026 | Visarjan |

Dates per the Bengal panchang. Ashtami and Navami share 19 October in 2026 because the Ashtami tithi ends at 10:53 AM that day.

## Features

- Live countdown (days / hours / minutes / seconds) that automatically rolls to the next key moment — Mahalaya, then Shashthi, Saptami, Ashtami/Navami, Dashami
- Auto-highlights today's card in the schedule
- After Visarjan, shows "Shubho Bijoya — Asche bochhor abar hobe"
- All timings in IST; fully responsive and mobile-friendly

## Run it

Just open `index.html` in a browser, or serve it with any static web server.
